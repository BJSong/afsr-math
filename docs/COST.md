# 비용 분석

> 무료 요금제의 한계를 임의로 가정하지 않음. 아래는 2026-10 기준 공개 요금제 기준 추정치이며,
> 실제 운영 전 각 서비스의 최신 요금제를 확인할 것.

## 무료로 시작 가능한 구성

| 서비스 | 무료 범위 | 비고 |
|---|---|---|
| Vercel (Hobby) | 월 100GB 대역폭, Serverless 실행 | 개인·소규모에 충분. 상업 이용 시 Pro 검토 |
| Supabase (Free) | 500MB DB, 월 5만 MAU, 5GB 대역폭 | 초기 사용자 수십~수백 명 충분 |
| GitHub Actions | 월 2,000분 | CI/E2E에 충분 |
| Upstash Redis | 일 1만 명령 (월 ~30만) | Rate Limit 전환 시 (Phase 3) |

## 무료 요금제 주의사항 (운영 직결)

- **Supabase Free — 7일 미사용 시 프로젝트 자동 일시정지:** 7일간 API 요청이 없으면 Postgres 인스턴스가 pause되고,
  재개 시 첫 요청이 10~30초 cold start를 탄다. 하루 한 번 쓰는 학습 앱에는 직접적인 운영 리스크.
  대안: Pro $25/월 (프로젝트당 — 8GB DB·250GB 대역폭·100GB 스토리지·10만 MAU·일시정지 없음·일일 백업).
- **Supabase Free — 한도 초과 시 402로 전 서비스 중단:** egress 등 한도 초과 시 앱이 통째로 멈춘다.
  학습 기록은 사라지지 않지만, cloud 전환 시 사용량 알림 설정이 필요하다.
- **Vercel Hobby — 비상업적 개인 용도 전용:** 지금 단계에선 문제없지만, 유료화·상업 운영 시 Pro($20/월)로 이전.
  한도 초과 시 기능 일시정지 방식이라 예상 밖 청구는 없음.

## 비용 발생 요소 (사용자 증가 시)

1. **Supabase**
   - DB 500MB 초과 → Pro ($25/월). 학습 기록은 텍스트 위주라 수천 명까지도 여유 있음.
   - PITR(시점 복구)은 Pro 이상. RPO 요구사항에 따라 결정.
   - 대역폭 5GB/월 초과 시 과금.
2. **Vercel**
   - Hobby 대역폭 100GB 초과 → Pro($20/월/인). 이미지 없는 텍스트 앱이라 초과 가능성 낮음.
   - Serverless 실행 시간: 문제 생성은 가벼운 연산이라 무료 범위 내.
3. **모니터링** (Sentry 등): 무료 티어로 시작 가능.

## 비용을 낮추는 설계

- 문제 생성은 클라이언트 요청 시 서버에서 즉시 생성 (별도 AI API 비용 없음)
- 정답 보관은 TTL 4시간 후 정리 (DB 용량 관리)
- 오답 노트·학습 기록은 집계 위주 저장 (원시 이벤트 장기 보관 지양)
- 이미지 미사용 → 대역폭·스토리지 비용 최소

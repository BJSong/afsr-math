# 학습 알고리즘 명세

> ⚠ **검증 상태 구분** (명세 2.3)
> - **연구 지지 원칙**: Mastery Learning, Retrieval Practice, Spaced Practice, Interleaving,
>   Explicit Instruction — 교육 연구에서 효과가 지지되는 일반 원칙으로, 설계에 반영함.
> - **초기 설계 가설**: 아래 우선순위 가중치(0.35/0.25/0.20/0.20), 임계값(90%/80%),
>   복습 간격(1→3→7→14→30일), 난이도 점수식은 본 프로젝트의 가설이며 과학적으로
>   입증된 값이 아님. `lib/policy.ts`에서 변경 가능하며, 학습 데이터에 따라 조정 예정.
> - 효과 검증 설계: 사전·사후 평가, 지연 복습 정답률, 전이 문제 해결률을 대시보드에 집계.

## 1. 문제 생성

- 자릿수: `[min,max]` 범위에서 자리수를 먼저 뽑고, 첫 자리가 0이 되지 않도록 생성
- 받아올림/받아내림: 세로셈 기준 실제 횟수를 세어 `none`/`required` 조건 필터링
- 나눗셈: **역생성** — 제수(d)와 몫(q)을 먼저 뽑고 피제수(d·q+r) 계산 후
  피제수 자릿수가 지정 범위를 만족하는지 반드시 검증. 제수는 0 제외.
- 중복 방지: `operator:operands` 서명 Set으로 세트 내 중복 제거
- 출제 불가능 조건(예: 1자리−1자리+받아내림 필수+음수 불허)은 `ImpossibleProblemError`
- 무한 반복 방지: 조건 필터 최대 2000회 시도 후 실패 시 에러

## 2. 난이도 판정

```
score = (a자릿수 + b자릿수 − 2) × 1.0
      + 받아올림 × 1.5 + 받아내림 × 1.5
      + 곱셈 부분곱 올림 × 1.0
      + (나눗셈: (제수 자릿수−1) × 1.0 + 나머지 0.5)
      + (혼합 출제: 1.0)
판정: score < 2.5 → 쉬움, < 5 → 보통, 그 외 → 어려움
```

예: `48+27`(받아올림 1회) = 1.0+1.5 = 2.5 → 보통 / `48×25`(부분곱 올림 3회) = 2+3 = 5 → 어려움.
자릿수가 같아도 받아올림 횟수에 따라 난이도가 달라진다 (명세 6.2).

## 3. 출제 우선순위

```
P(s) = 0.35·E + 0.25·R + 0.20·F + 0.20·T   (가중치는 정책에서 변경 가능, 합 1로 정규화)
E (최근 오류): 1 − 최근 10회 정답률 (기록 없으면 0.4)
R (복습 필요): 예정일 경과 시 0.5 + 경과일/간격 (최대 1), 예정 전이면 0
F (유창성): 정답률 80% 이상이고 중앙 풀이시간이 목표의 2배면 1
T (전이): 전이 문제 미시도 0.5, 실패 1.0, 성공 0
```

선수 학습 미충족 스킬은 후보에서 제외 (`prerequisitesMet`).

## 4. 난이도 조절

| 조건 | 조치 |
|---|---|
| 최근 5회 미만 | hold (판단 근거 부족) |
| 정확도 ≥ 90%, 느림(목표×1.5 초과) | fluency-practice (유창성 연습) |
| 정확도 ≥ 90% | expand (점진적 확장) |
| 정확도 80–89% | hold (동일 수준) |
| 빠름(목표×0.6 미만) + 정확도 < 80% | remove-pressure (시간 압박 제거) |
| 정확도 < 80% | reteach (개념·전략 재학습) |

## 5. 숙달 상태

`new → learning → practicing → provisional_mastery → retained`

- `practicing → provisional_mastery`: 시도 20회 이상 + 최근 정확도 90% 이상
- `provisional_mastery → retained`: 예정된 복습 성공
- 복습 실패: `retained`/`provisional_mastery → practicing`, 그 외 → `learning`
- 정확도 급락(< 60%): 단계 강등
- 소수 시도로 숙달 확정 금지 (`minAttemptsForMastery = 20`)

## 6. 간격 복습

기본 간격: 1일 → 3일 → 7일 → 14일 → 30일. 복습 성공 시 다음 단계, 실패 시 1일로 초기화.
동일 문제 반복보다 **동일 개념의 새로운 문제**를 우선 출제한다.

## 7. 오답 분석

최종 답안 기반 휴리스틱:
- 다른 연산의 정답과 정확히 일치 → **연산자 혼동** (확정, estimated=false)
- 정답의 10배/1/10 → **자리값 오류** (추정)
- 정답과 차이가 10의 배수 → **받아올림/받아내림 오류** (추정)
- 패턴 없음 → **기본 계산 오류** (추정)

오답 처리: 정답 확인 → 패턴 분석 → 개념 설명 → 전략 안내 → 유사 문제 → 복습 일정 반영.
